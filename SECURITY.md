# Security

## Reporting a problem

Please report security problems privately: on GitHub, open the **Security** tab of this repo and choose **Report a vulnerability**. Don't open a public issue. You'll get a reply within a week.

## Supported versions

Only the latest release gets fixes. Update with `git pull` in the install folder.

## What's in scope

Anything that lets someone without the token control a TV, read the watch diary, run Claude, or get admin rights on the Mac; and anything on a TV screen or in a show description that can make Claude act on it. The README's Security section lists the known, accepted risks.
